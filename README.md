Данное приложение написано в ходе прохождения курса python-developer.

# Технологии
Python
Django
uv

# установка приложения
после клонирования репозитория надо установить пакеты в виртуальное окружение:
```shell
make install
```
# использование
## 1. подключение к БД
По умолчанию используется sqlite3.
Для этого необходимо переименовать файл `.env_example` в `.env` и в начале строки: `DATABASE_URL=psql://user:user-password@127.0.0.1:8458/database` поставить `#` (закомментировать)
Если нужно успользовать другую БД - см. комментарии в самом файле.

## 2. установка секрета
в файле `.env` необходимо поменять `your_secret_keys` в переменной `SECRET_KEY=` на ваш пароль.

## 3. запуск сервера
Для работы вы можете в файле `.env` удалить строку (переменную) `DEBUG = True`. Это действие отключит `debug-режим`.
Для запуска сервера введите в терминале:
```shell
make start
```
